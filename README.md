# 프로거 🐸

추억의 오락실 프로거(Konami/Sega, 1981)를 본뜬 혼자 하는 게임입니다. 서버 없이 `index.html` 만 열면 돌아갑니다.

- 조작: 방향키/WASD 로 **한 칸씩 뜀**(꾹 누르면 계속). 폰은 아래 화살표 버튼이나 화면 쓸기(톡 치면 앞으로).
- `P` 일시정지, `M` 소리.
- 규칙은 `logic.js`(DOM 없음), 화면·소리·입력은 `game.js`. 시험: `node --test`.

## 규칙
- 15×13 칸: 맨 위 집 5칸 → 강 5줄(통나무·거북이) → 가운데 둔덕 → 도로 5줄(트럭·경주차·승용차·불도저) → 출발 줄.
- 한 마리마다 **30초**. 새 줄에 처음 갈 때마다 10점, 집에 들어가면 50점 + 남은 시간(0.5초당 10점). 집 다섯 칸을 모두 채우면 1000점 + 다음 레벨. 20000점에 한 마리 추가(한 번).
- 죽는 경우: 차에 치임 · 물에 빠짐 · 통나무/거북이에 실려 화면 밖으로 밀림 · 가라앉은 거북이 · 집 칸 사이 벽이나 이미 찬 집에 부딪힘 · 집 안의 악어 · 뱀 · 시간 초과.
- 거북이는 주기적으로 가라앉습니다(가라앉는 중에는 색이 변하지만 아직 탈 수 있음). 집 칸에 나타난 파리 200점, 통나무 위 분홍 개구리를 집까지 업고 가면 200점.
- 레벨 2부터 둔덕에 뱀과 긴 통나무 줄의 악어(입이 열렸을 때 머리가 위험, 몸통은 안전), 레벨 3부터 집 안의 악어. 레벨이 오를수록 속도가 9%씩 빨라지고(최대 2.2배) 가라앉는 거북이가 늘어납니다.

## 참고한 것과 확인하지 못한 값
- 공개 자료([Wikipedia](https://en.wikipedia.org/wiki/Frogger), [arcade-history](https://www.arcade-history.com/game/879/frogger-model-gx392))에서 확인: 집 5칸 · 강과 도로 · 파리·암컷 개구리 200점 · 5칸 완성 1000점 · 앞으로 한 칸 10점 · 집 50점 · 남은 0.5초당 10점 · 20000점 추가 목숨.
- 제가 정한 값(자료마다 달라 확정하지 못함): 제한 시간 30초, 시작 목숨 3, 줄마다의 종류·길이·간격·속도, 거북이가 가라앉는 주기(7초), 악어 입 주기(5초), 뱀 속도, 레벨별 가속과 등장 시점, 15×13 칸 크기. 원작의 줄 순서와 속도표를 그대로 옮긴 것이 아닙니다. 수달은 자료가 확실하지 않아 넣지 않았습니다.
- 그림·소리는 직접 그린/합성한 것입니다.
